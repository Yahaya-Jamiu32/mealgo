# MealGo — Food Delivery Landing Page
Self-initiated portfolio concept (Project 03). HTML5, CSS3, JavaScript, Bootstrap 5 + Bootstrap Icons (loaded from CDN, so open it online).

## Run
Open `index.html`, or `npx serve .`

## Structure
- `index.html` — page markup
- `css/mealgo.css` — brand tokens and Bootstrap overrides
- `js/mealgo.js` — data, search, category filter, cart, login and contact forms
- `assets/images/projects/mealgo/` — images

## Images
All images were cropped from the supplied MealGo mockup, so they are low resolution. Replace them with your real assets, keeping the file names:
01-MealGo-Hero, 02-MealGo-Restaurant-*, 03-MealGo-Featured-Meal, 04-MealGo-Discovery, 05-MealGo-Order-Tracking, 06-MealGo-Mobile, 07-MealGo-Final-Mockup.
Any image that fails to load falls back to a styled MealGo placeholder.

## Notes
Login, contact, cart and checkout are front-end demos with no backend. Restaurants are fictional.
